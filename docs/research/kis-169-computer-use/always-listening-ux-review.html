The seven user-visible states

Each card shows the exact indicator treatment proposed for that state, plus the governing rules.

no Suniye surface visible
1 Off
Voice Activation disabled. No wake-phrase processing, no mic use beyond normal dictation.
Menu bar: plain icon, “Voice Activation Off”. Turning it on moves to Ready.
◎
2 Ready
Waiting for “Hey Suniye.” Represented in the menu bar only — a quiet persistent listening indicator. No floating panel.
Rule: ambient speech is never shown in chat or history. macOS mic indicator stays visible — a deliberate privacy promise.
Listening…✕
3 Listening
After wake-up: cue sound (optional), live level meter, Cancel. The user speaks naturally — no key held. Turn end is detected automatically.
Rule: captured transcript flashes briefly before submission so recognition mistakes are visible. Silence → back to Ready, no chat turn.
Working…Open
4 Working
Compact generic working state: shimmer label, one Stop control, Open-conversation action. No transport details.
Rule: the Computer Use window does not open automatically. Exactly one Stop control per surface.
Listening…task running
5 Listening during a task
“Hey Suniye” while Working accepts a correction, follow-up, or stop request as a new turn in the same conversation.
Rule: no exact phrase matching — meaning comes from the full turn plus context. An in-flight atomic action finishes first; the correction governs the next decision.
Needs your inputOpen
6 Needs input
The task cannot continue without the user. Distinct, non-alarming accent; optional subtle prompt sound. Answer by voice: “Hey Suniye, …”.
Rule: Suniye must not repeatedly announce — or display — sensitive information while waiting.
✓Done — battery is at 91%, Normal condition
7 Completed / Stopped / Failed
Brief terminal flash: Done with the final response, Stopped, or Couldn’t finish with a short reason + Open action. Auto-dismisses.
Rule: returns to Ready and preserves the conversation. The next wake-up continues it; a new conversation only on explicit New/Clear.
